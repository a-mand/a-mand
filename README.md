<a name="Pesquisa"></a>
<img src="https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/versions/generation-v/black-white/animated/196.gif" height="48" align="middle" alt="Espeon" /> <img align="middle" src="https://readme-typing-svg.herokuapp.com?font=Fira+Code&weight=600&size=26&duration=2200&pause=600000&color=3FB8AF&vCenter=true&width=640&height=50&lines=Pesquisa" alt="Pesquisa" />

Pesquisa no **Laboratório de Cidades Inteligentes e Sustentáveis (LaCIS)** da UFPA, como bolsista do **CNPq**.

O laboratório estuda tecnologias para cidades mais conectadas, eficientes e sustentáveis. Nesse contexto, a pesquisa se concentra em **Aprendizado Federado aplicado a redes veiculares**: veículos treinam um modelo de forma colaborativa, sem compartilhar seus dados brutos, o que preserva a privacidade e reduz o tráfego na rede.

**Principal desafio estudado:** as redes veiculares têm mobilidade alta, conexões instáveis e dispositivos com recursos limitados. A pesquisa trata de decidir **quais veículos devem participar de cada rodada de treinamento**, para que o modelo convirja com mais rapidez e qualidade.

**Temas de interesse:** Aprendizado Federado, seleção de clientes, redes veiculares (VANETs), sistemas distribuídos, segurança de modelos de Machine Learning e Machine Learning para cidades inteligentes.
